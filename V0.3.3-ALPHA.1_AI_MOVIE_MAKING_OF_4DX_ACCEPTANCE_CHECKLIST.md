# v0.3.3-alpha.1 Acceptance Checklist

## Special Skill and Design UI

- [ ] `ai-movie-making-of-4dx` appears in the Special Skill list and loads its Design Requirement template.
- [ ] A new project selects all ten effect controls by default.
- [ ] Duration status updates immediately after an effect selection changes.
- [ ] One selected effect resolves an authored 15-second target to 15 seconds.
- [ ] Ten selected effects raise an authored 15-second target to the required 60 seconds.
- [ ] A target longer than the calculated minimum remains unchanged.
- [ ] The managed 4DX block records selected count, authored target, calculated minimum and resolved duration.
- [ ] The ten effect controls can be independently selected and deselected.
- [ ] Intensity and Density are independent.
- [ ] A control change replaces only the managed 4DX block and preserves the user's story.
- [ ] Other Skills and no-Skill Design do not show the 4DX controls.

## Complete Film Format

- [ ] Duration follows `15s + 5s × (selected effects − 1)`, from 15 seconds for one effect to 60 seconds for ten effects.
- [ ] The Timeline contains one intro, ten effect chapters and one Final Hold when all controls are selected.
- [ ] Every effect chapter keeps its screen event, active theatre mechanism and audience reaction visible together for at least 99% of the chapter.
- [ ] Every effect chapter contains one visible screen-plane crossing; the effect-bearing element occludes part of the still-readable screen border and continues into the front-row airspace.
- [ ] Exactly one source subject remains present; no duplicate aircraft, vehicle, person, detached hologram, portal or second full-size subject appears in the auditorium.
- [ ] The old Source Photography / Reference Analysis / Character Extraction tutorial sequence is absent.
- [ ] Every frame is covered by one Shot without gap or overlap.
- [ ] Each selected effect chapter reaches the actual H3 Shot prompt.
- [ ] Technical labels are editable Timeline layers rather than H3/Z-Image lettering.
- [ ] The final second is stable and starts no new speech, action or effect.
- [ ] Intro and Final Hold use only 0.5 seconds each; Final Hold retains visible residual effects without starting a new event.

## Media and Scene Composition

- [ ] Enabled P/V/A media appears in an authority-ranked Reference Role Ledger.
- [ ] Explicit user mapping and source pixels outrank AI Enrich and BLIP.
- [ ] Filenames never define scene content.
- [ ] P1-P9 have no hardcoded meaning.
- [ ] Existing media is reused before missing references are requested.
- [ ] Z-Image creates no more than one time-scoped scene plate per selected effect and no per-Shot alternates.

## Physical Events and 4DX Events

- [ ] Physical Events and 4DX Events are stored separately with stable linked IDs.
- [ ] Every used effect has a visible causal source.
- [ ] Every selected demonstration deliberately creates one compatible visible cause instead of silently skipping the effect.
- [ ] Every default chapter uses an original genre scene and does not request copyrighted film characters, logos or exact scene copies.
- [ ] Camera movement is never mapped as seat movement.
- [ ] Intensity changes magnitude without silently changing density.
- [ ] Density changes frequency without silently changing intensity.
- [ ] Manual events are preserved over later automatic planning.
- [ ] Every chapter shows multiple distinct audience reactions appropriate to its effect and force direction.
- [ ] Audience surprise follows spatial causality: front row first and directional, middle rows slightly later, rear rows smaller and later.
- [ ] FPV physically translates around audience rows; no visible drone, in-place spin, barrel roll or zoom-out appears.

## Native Audio and Compatibility

- [ ] H3 receives diegetic auditorium sound only: screen event, seat mechanisms, effect equipment and audience response.
- [ ] Each active chapter keeps four clearly audible native layers: front-screen event, near-field seat/mechanism Foley, directional environmental effect and staggered audience reactions.
- [ ] Selecting this Skill overrides global `MUSIC AUTO` during H3 compilation; no score, musical drone or trailer cue reaches the request.
- [ ] Native Audio identifies a large 4DX cinema and never misclassifies the venue as an office or other generic room.
- [ ] A user-edited Native Audio Direction is preserved without automatic replacement.
- [ ] No Voice-over, Dialogue or Lyrics Text Layer is generated by this Skill.
- [ ] No banquet hall, conference room, computer lab, office, dining table or gaming simulator replaces the 4DX cinema.
- [ ] No TTS replacement, speech separation, FFmpeg reverb, EQ, convolution or post-mix chain is added.
- [ ] Apply Undo/Redo restores the Experience Design and both event families.
- [ ] Project save/load restores preferences, ledger, Physical Events and 4DX Events.
- [ ] A v24 or older Project loads with safe defaults.
- [ ] Ordinary Skills, Storyboard, Auto Cut, Segment Mapping and Smart Render remain operational.
