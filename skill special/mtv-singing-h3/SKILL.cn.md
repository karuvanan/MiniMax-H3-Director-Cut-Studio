# MTV 唱歌 H3

这个 Skill 把素材角色固定为：P1 主唱、P2/P3 陪衬人物、P4 场景母版、A1 唯一原音主轨，并自动把 P5-P9 生成为五个由 P4 派生的分时环境／灯光状态。

核心原则是“画面跟歌走，声音不重唱”：MiniMax H3 使用 A1 的对应时间窗驱动 P1 的嘴形、呼吸、表情和动作；成片发布时，Studio 用原始 A1 时间线音轨替换 H3 新生成的音频，避免走调、换声、歌词改变或每段重播歌曲开头。

口型生成采用最多7秒、建议5至7秒的隐藏Segment。每段只能收到Timeline同一位置的A1切片；Segment边界不代表歌词、乐句或呼吸结束。若H3半秒时间格令最后一段比A1真实结尾多出不超过0.5秒，只可保留A1真实尾音并在歌曲结束后补极短静音，绝不能从A1开头重播。

片长不再固定为12秒。Studio会以A1的完整可播放源音频长度作为Design、Timeline、Shot、P5-P9时段和最终输出的时长权威；如果用户明确设定A1 source-in/source-out，则以该可播放窗口为准。旧Timeline或模板里的数字不得裁掉歌曲结尾。

如果用户没有提供逐字歌词，不得虚构 Lyrics、Dialogue 或 Voice-over。混合歌曲的Whisper/ASR结果只可作为分析资料，不能写入对白、旁白、歌词或H3叙事提示词；也不得猜测主歌、高潮、末句或自行规定嘴巴开合。若提供逐字歌词，只把它们作为 A6 上可编辑的歌词时间层，固定 Speaker=S1、Lip Sync=true；真正听到的歌曲仍然是 A1。

P2/P3是无声陪衬人物，P1演唱时保持自然闭口或明确的非发声反应；多人同框时只有P1可以正面呈现清晰演唱口型，除非用户明确指定另一位歌手。

每个生成Segment在进入可复用缓存前，必须以H3未修改的输出音频对照该段A1执行Singing Lip-Sync QC，检查整体节奏、起音、后段锁定与时间偏移。失败不得暂停整个Job：系统自动把该段调整为P1正面或清晰四分之三侧面演唱、嘴唇与下颌无遮挡、P2/P3静默且保持非发声嘴形，然后重新生成，最多自动修复五次。五次仍未达标时继续完成Job并显示Warning，该段不得作为已通过QC的缓存复用。质检只分析，不修音、不混音。
