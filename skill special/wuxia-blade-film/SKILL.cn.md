# 武侠电影 · 刀

创作危险、即兴、具有严格物理连续性的武侠动作。把本 Skill 的场景动作规则与 Studio 已绑定的 Default H3 Prompt Writing Skill 一起使用。

## 规划战斗

1. 提取影片时长、故事地点、人物身份、武器归属、戏剧目标、参考素材和结尾要求。
2. 为每名角色建立不同的战斗语法。优先采用不对称组合，例如沉重强攻对快速应变。
3. 建立时间准确、按顺序排列的 Shot Blocks。每个 Shot 必须说明景别、机位、镜头运动、主体动作、环境反应和补充导演指示。
4. 在每个边界记录进入时的身体姿势、武器状态、速度和画面运动方向。下一个 Shot 的第一个动作必须继承这些状态。
5. 只保留少量标志性招式作完整清晰展示。其他打斗通过局部、遮挡、近距离撞击和动作后果表达。

## 使用因果动作链

每次交锋使用以下结构：

`继承状态 -> 触发原因 -> 已承诺动作 -> 接触 -> 后果 -> 离场方向`

- 在物理上可行时，让下一个动作在上一个动作完全结束前开始。
- 招式之间绝不让角色重置为中立站姿。
- 让失败的攻击直接启动下一项策略：被挡开的飞镖变成反弹暗器，受压的短刀促使角色下沉甩链，被抓住的链索变成膝撞的牵引力。
- 严格保持武器数量、归属和刚性。没有可见交接动作时，不得复制、变形或转移武器。
- 在剪切、甩镜和重新捕捉主体的过程中，保持可理解的动量方向。

## 区分交战双方

沉重刀手：

- 使用大幅度、已经投入力量的劈、扫、压、撞，以及重量和距离优势。
- 避免装饰性旋转和频繁更换武器。
- 落空的重击必须破坏环境或制造新的动作机会。

敏捷攻击者：

- 在对手恢复前不断改变距离、高度、方向或使用的武器。
- 把对手的力量转成自己的变向动力，不要直接停止动量。
- 只有在来源和持有关系清楚时，才使用暗器、链索、衣物或环境碎片。

## 让轻功服从物理

禁止没有原因的漂浮。每一次空中加速或变向都必须至少具有一个可见物理来源：

- 腿部压缩和爆发；
- 墙面、屋顶、横梁、地面或水面接触；
- 链索张力；
- 碰撞力量；
- 已经存在的空中动量。

接触动作必须短促而清晰。除非故事明确要求长距离水上奔跑，否则踏水只用于一次猛烈变向。

## 导演镜头

- 使用近距离攻击性手持镜头、暗器跟拍、延迟甩镜、荷兰角追逐、低机位快速仰拍和极速拉远。
- 允许镜头偶尔跟丢更快的角色。重新找到角色时，他应当已经进入下一项动作。
- 允许武器局部冲出画面，并使用眼睛、手、刀锋、肩膀、脚、衣物、火花、灰尘、瓦片和水花等碎片细节。
- 不要隐藏全部动作。大约四十五秒的影片中，只需完整清楚地展示约三个标志性招式。
- Bullet-time 只用于关键碰撞前的一次决策，并在恢复接触时立即结束。
- 在撞击、遮挡、物体掠过镜头或连续方向运动时剪切。不得利用剪切让角色瞬移或无声换位。

## 同步环境反应

环境反应必须具有清楚的物理原因：

- 脚步令瓦片裂开或移动；
- 刀刃接触产生短促火花；
- 链索绷紧时牵动衣服和身体；
- 踩墙产生灰尘或细小裂纹；
- 只有脚、身体或武器接触时，水面才产生反应；
- 落叶和衣服必须跟随空气压力与速度。

优先使用短促、坚硬的现场声，例如 `WHOOSH`、`CLANG`、`THUD`、`CHAIN SNAP`、`TILE CRACK`、`BLADE SCRAPE`、`HEAVY BREATH` 和 `WATER IMPACT`。高速动作的声音应短而干。除非用户明确要求，否则避免随机能量光束和装饰性魔法爆炸。

## 有目的地使用参考素材

- 只使用稳定的 `@P`、`@V` 或 `@A` ID 引用已经加载的 Media Pool 素材。
- 保留有效参考素材中的人物身份、服装、武器归属、建筑、地理关系和光线。
- 人物身份与环境参考可在适当情况下覆盖完整设计；动作状态参考只在需要的时间范围内激活。
- 只生成真正缺少的参考素材。不要为每一个 Shot 都生成图片，也不要习惯性填满全部栏位。
- 每张生成参考图必须独立、完整地描述真实故事地点中的画面，不得要求复制之前或之后生成的帧。

## 输出 Design 结果

遵守应用当前提供的 Director Design JSON Schema。要求 JSON 时只返回 JSON。

- 使用准确的开始和结束时间，并保持连续的时间覆盖。
- 在 `subject_action` 写入明确的物理动作。
- 在 `environment_response` 写入由接触引发的场景反应。
- 在 `additional_direction` 写入继承状态、离场方向、动作可见性、镜头重新捕捉方式和武器连续性。
- 只有实际控制边界、撞击、揭示或结尾时，才加入 Transition 和 Marker 指示。
- 只有用户明确要求时，才使用对白或可见文字。
- 结尾必须是最后一击自然产生的后果、逃离、视觉呼应或 Final Hold，不得突然加入无关的新动作。

## 质量检查

输出前确认：

- 每个 Shot 都从上一个 Shot 的准确结束状态开始；
- 没有中立姿势重置、瞬移或缺乏原因的空中运动；
- 每件武器的所有者、数量和形态始终清楚；
- 沉重刀手与敏捷攻击者保持不同的动作风格；
- 环境和声音只对真实物理原因作出反应；
- 只有选定的标志性招式得到清楚完整的全身展示；
- 结尾解决既有动作，不建立新的断裂情节。
