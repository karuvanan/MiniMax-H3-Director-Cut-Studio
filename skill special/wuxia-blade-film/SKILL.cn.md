# 武侠电影 · 刀

创作危险、即兴、具有严格物理连续性的武侠动作。把本 Skill 的场景动作规则与 Studio 已绑定的 Default H3 Prompt Writing Skill 一起使用。

## 规划战斗

1. 提取影片时长、故事地点、人物身份、武器归属、戏剧目标、参考素材和结尾要求。
2. 为每名角色建立不同的战斗语法。优先采用不对称组合，例如沉重强攻对快速应变。
3. 建立时间准确、按顺序排列的 Shot Blocks。每个 Shot 必须说明景别、机位、镜头运动、主体动作、环境反应和补充导演指示。
4. 在每个边界记录进入时的身体姿势、武器状态、速度和画面运动方向。下一个 Shot 的第一个动作必须继承这些状态。
5. 只保留少量标志性招式作完整清晰展示。其他打斗通过局部、遮挡、近距离撞击和动作后果表达。
6. Timeline 超过 15 秒时，在不破坏节奏的情况下，让主要戏剧阶段对齐原生 15 秒窗口。不得让生成边界清除动作的物理状态。

## 准备干净的 Design 输入

- 只提供一层权威需求。绑定 Skill 已经提供共通规则时，不要把同一个 Shot 重复写成中文大纲、英文 Prompt 和 Global Action Prompt。
- 时长、准确 Shot 范围、画面文字／对白政策、人物与武器账本、空间账本、边界合同、声音和素材政策都只写一次。
- Shot 指令必须足够具体，可直接进入 `subject_action`、`environment_response` 和 `additional_direction`；不要加入“如何强迫模型”的讨论。

## 执行 H3 生成预算

写入每个 Shot 前，先把指令分成四级：

- **必须完成的核心动作（`subject_action`）：** 画面必须明确完成的最小因果动作。每 5 秒最多三个物理动作节点。
- **必须保持的状态（`continuity_state`）：** 进入与离开 Shot 时的身体姿势、武器归属和位置、速度、画面方向、空间位置、镜头轨迹，以及尚未解除的接触关系。
- **可以省略的装饰动作（`optional_flourish`）：** 落叶、火花、灰尘、衣物运动、次要佯攻、装饰性镜头运动，以及删除后不会破坏剧情的细节。
- **必须出现的动作后果（`environment_response`）：** 用来证明因果关系的接触反应，每 5 秒最多两个。必要的撞击、落地、断裂或触水不得误放入装饰动作。

每个 5 秒区间最多安排三个必须完成的物理动作、两个必要接触后果和两个可选装饰。超过预算时：

1. 时间足够时，优先按照 0.5 秒网格拆成连续、互不重叠的 Shot Blocks。
2. 无法再拆时，保留触发原因、主动作、决定性接触／后果和离场状态；把次要攻击、重复反击和装饰反应降级到 `optional_flourish`。
3. 把留下的核心改写成一条简洁、可执行的因果链。不得因为原稿把所有构思都称为重要，就保留模型不可能完成的动作清单。
4. 每个原生 15 秒边界前最后 0.5 至 1.0 秒不得再开始新的多步骤招式，只建立一个清楚的离开状态交给下一段。

固定优先顺序为：人物身份／空间／武器归属与连续状态，其次是核心动作，再其次是必要接触后果，最后才是可选装饰。H3 必须先省略装饰，绝不能为了装饰而延迟、削弱或重播核心动作。

## 锁定连续性账本

编写 Shot 前先固定四份账本：

- **人物账本：** 准确人物数量、身份、服装和战斗语法。
- **武器账本：** 准确武器数量、所有者、持有手、形状和允许用途。每件武器只使用一个名称，不得在链索、链刃和飞索等含义不同的名称之间切换。
- **消耗品／道具账本：** 计算飞镖等消耗品的数量并指定每一次用途。追踪斗笠等延迟回调道具的完整生命周期；为其提供真实的落点、卡住状态或回收状态，避免不可能的滞空时间。
- **空间账本：** 定义屋顶、墙、桥、池、树木和地标的相对位置。角色改变高度或地点时必须具有可见移动路径。

必须消除含糊动词。使用“撤去格挡压力但继续握住短刀”，不要写“松刀”；使用“铁钩脱离并收回同一条链索”，不要写“释放链子”；明确刀光是佯攻、擦过甲胄还是真正伤口。

## 编写边界合同

每个 Shot 边界，尤其每个原生 15 秒边界，都必须记录：

1. 离开边界时的身体位置、武器位置、速度、画面方向和相关环境状态；
2. 边界之后的第一项新动作；
3. 明确禁止重播的上一项动作。

原生生成边界优先使用撞击遮挡、掠过镜头的道具或持续方向运动。下一段可以继承最后的动作帧，但必须从这些帧向前发展，不得重新生成起跳、攻击或落地。如果人物在画外到达屋顶或桥面，剪切前必须建立他的接触点或起跳路径。

## 使用因果动作链

每次交锋使用以下结构：

`继承状态 -> 触发原因 -> 已承诺动作 -> 接触 -> 后果 -> 离场方向`

- 在物理上可行时，让下一个动作在上一个动作完全结束前开始。
- 招式之间绝不让角色重置为中立站姿。
- 让失败的攻击直接启动下一项策略：被挡开的飞镖变成反弹暗器，受压的短刀促使角色下沉甩链，被抓住的链索变成膝撞的牵引力。
- 严格保持武器数量、归属和刚性。没有可见交接动作时，不得复制、变形或转移武器。
- 明确计算消耗性武器的数量，并禁止超过该数量的额外使用。
- 在剪切、甩镜和重新捕捉主体的过程中，保持可理解的动量方向。

## 区分交战双方

沉重刀手：

- 使用大幅度、已经投入力量的劈、扫、压、撞，以及重量和距离优势。
- 避免装饰性旋转和频繁更换武器。
- 落空的重击必须破坏环境或制造新的动作机会。

敏捷攻击者：

- 在对手恢复前不断改变距离、高度、方向或使用的武器。
- 把对手的力量转成自己的变向动力，不要直接停止动量。
- 只有在来源和持有关系清楚时，才使用暗器、链索、衣物或环境碎片。

## 使用惨烈刀战动作语法

提取九十年代香港刀战中可复用的动作原则，不逐镜复制任何电影。拒绝整齐的攻防轮流、对称拆招、装饰性 Pose 和干净的超级英雄式飞行。战斗必须显得即兴、急促并付出身体代价：重击落空会造成危险，受伤会改变下一步动作，人物依靠切入兵器失效的距离或偷取对手动量生存。

不得把游戏用的帧数、冷却、伤害百分比、Buff 或资源值直接写入 H3 Prompt。它们只能作为编舞优先级参考，最终必须转换成可见距离、身体力学、接触、后果和恢复状态。

### 锁定身体不对称、武器几何与伤势

选择招式前先冻结以下账本：

- **肢体账本：** 写清楚每一条缺失、受伤、被占用或可使用的肢体。独臂人物必须注明剩余手臂和持刀手，空袖始终为空；禁止重新长出手、幽灵握持、双手格挡或用不存在的手维持平衡。原图无法明确表现时，生成一张能看清独臂轮廓的身份参考图。
- **武器几何账本：** 记录刀身长度、弧度、重量、刀尖状态、刀刃状态、持有手及连接物。断刀没有可用刀尖时，禁止干净直刺或贯穿；改用拉割、推切、向上刮切、卡压和断背撞击。若断口具有可穿刺的尖角，只能明确一次并始终保持同一形状。
- **连接账本：** 明确链索从哪里开始、缠绕或钩住什么、当前绷紧或松弛、由哪只手控制，以及怎样脱钩或收回。不得让一条链突然变成第二件武器或穿过人体。
- **伤势账本：** 把每处刀伤、瘀伤、破袖、甲片损坏、腿部无力、呼吸损耗、血迹、泥污和握力下降带进后续 Shot。伤势必须改变姿态、速度、距离或格挡意愿，不得在切镜或 15 秒边界后消失。
- **脚下账本：** 追踪干燥石板、松瓦、泥地、血迹、池边及碎片。滑倒、踉跄、地面翻滚或起跳失败必须来自可见地面状态。

不得把独臂人物描述成无条件加速或免疫控制。必须展示代价：距离和平衡变差，人物依靠更低轮廓、短刀较小惯性、躯干旋转、激进落脚，以及在长兵器收回前进入内圈进行补偿。

### 从招式逐步退化成求生

使用可控制的退化曲线，不要让整场战斗始终保持整齐武术形式：

1. **威胁：** 用一个短促空间镜头建立距离、高度、人数或脚下条件的不平等。
2. **承诺攻击：** 一方发动一次重到或快到无法取消的攻击；另一方必须通过改变距离生存，而不是摆出完美格挡 Pose。
3. **伤势适应：** 伤口、断兵器、手臂被困或失去立足点，必须在下一次交换立刻产生新的身体力学。
4. **野兽式崩解：** 只在高潮附近，把技巧退化成沉肩撞击、前臂卡压、踢击、地面挣扎、抢回武器和绝望短切。仍须保持准确人体和武器归属；“野兽式”不等于随机多肢或无法理解的混乱。
5. **代价：** 结尾停在喘息、倒下、武器无法使用、持续伤势或勉强逃离。胜利必须具有可见代价。

不得把五个阶段全部塞进同一个五秒 Shot。把退化曲线分布在整段影片，每个 Shot 只推进一项不可逆战斗状态。

### 让碎片剪辑保持动作因果

- 先建立一次空间，然后在眼神、落脚、握刀手、刀刃、破布、撞击和反冲之间切换。每个局部必须属于同一次相邻的身体交换。
- 兵器或身体掠过镜头只能遮挡撞击发生的一瞬；之后必须立刻显示新伤口、被移开的格挡或改变后的位置。
- 只有脚步落地、身体碰撞、刀刃接触或镜头闪避后才使用 Camera Shake。持续随机抖动不能制造速度。
- 长连斩用“第一条清楚攻击线 -> 压缩撞击碎片 -> 最终清楚后果”表达，禁止攻击者从同一 Pose 重新开始连斩。
- 每次交换保持一个方向锚点：画面运动方向、固定地标、对手肩线或可见链索轴线。

### 断刀内圈贴身流

短刀或断刀对抗长兵器时，锁定以下动作语法：

- 主要在一个身位以内作战。短刃贴近前臂，攻击使用紧凑直线，不画宽大的展示圆弧。
- 从已经投入力量的长兵器挥击下方或侧面切入，不在对方刀身最强的外三分之一位置硬挡。
- 使用沉肩撞击、前臂压力、低位滑步、躯干转轴，以及墙面、绳索或绷紧链条作为变向来源。
- 每一次转身必须产生新的切割角度或离场方向，不得为了好看而空转。
- 进入内圈后以胸口贴肩、肩压手肘，使长兵器无法完全收回；同一个短交换内必须完成攻击或退出。

可执行的标志性动作链：

1. **切入内门：** 低姿态停在长兵器范围外 -> 对方承诺一次大幅挥击 -> 短刀手下沉避开刀线并用肩撞入持械手臂 -> 一米内完成一次短促上刮或拉割；只有账本已经确认断口具有固定可用尖角时才允许直刺 -> 从对手后肩方向离开。
2. **张力轴心回旋：** 绳索或链条清楚绷紧于横梁、树干或身体轴点 -> 刀手种下一只脚并只旋转一次 -> 短刃在紧凑内弧截住来袭兵器 -> 张力把身体拉入新角度 -> 结尾必须看见同一条链仍由原主角持有、保持绷紧或已经收回。
3. **粘身短连击：** 肩膀压力卡住对手手肘 -> 一次短上撩迫使躯干打开 -> 一次手腕反转推切横过邻近目标线 -> 刀背、刀柄或前臂制造离场撞击。最多清楚表现三次接触；其余高速连续动作只用局部、声音与对手反应暗示。
4. **贴地反切：** 对手利用距离攻击上段 -> 短刀手折叠髋膝，以一只手或脚短暂撑地 -> 身体滑过长兵器回收线 -> 一次低切攻击暴露的侧腹或前腿 -> 完全越过对手后才起身。

### 凌空双刀掠食流

长双刀角色使用高度压制时，锁定以下动作语法：

- 每次升空必须出现起跳接触点：墙、屋檐、横梁、地面压缩或碰撞力。禁止长时间无支撑滞空。
- 空中危险来自高度与重力。只安排一次清楚的 X 形下劈、交替刀网或向下贯击，不设计失重芭蕾式连段。
- 双刀必须占据不同攻击线。两把刀同时重要时，要分别写明左刀和右刀轨迹；不得合并、复制或改变长度。
- 密集狂斩只清楚展示两至三次接触；其余通过刀锋冲出画面、火花、破布、喘息和镜头后震表达。不得要求 H3 数出九刀。
- 落地后必须立即变成追击、踉跄、滑行或反冲，不得在猛烈下坠后重置成平衡 Pose。

可执行的标志性动作链：

1. **恶鹰起跳与 X 形下坠：** 双脚压碎一个清楚的起跳点 -> 身体收折并升到目标上方 -> 双刀在左右两侧分开 -> 重力推动一次交叉向下攻击 -> 地面、格挡或肩膀承受撞击 -> 刀手以前冲滑步落地。
2. **重叠刀网：** 左刀承诺上段攻击，右刀同时封住中线 -> 对手格挡被迫向内收缩 -> 第三次低位或反手切割破坏架势 -> 衣物／火花遮挡或撞击镜头 -> 镜头重新捕捉动作后果，不再重新开始一轮狂斩。
3. **落地低位追杀：** 下坠结束时一脚一手接近地面 -> 刀手立即以不规则短步推进 -> 一把刀占据对手视线，另一把刀封死逃离路线 -> 以碰撞或清楚的落空暴露结束。

### 解决“一秒生死”速度悖论

长／高／重力优势对抗短／内圈／速度优势时，不要设计长时间势均力敌的拆招。只建立一条决定性因果链：

`长刀或双刀在外圈承诺攻击 -> 短刀手承受轻微擦伤或刚好避过一条刀线 -> 身体切进对方双肘以内 -> 长兵器尚未收回时完成一次紧凑决定性切割 -> 双方错身或倒入动作后果`

Bullet-time 只放在最后的决策空隙，故事时间最好少于半秒；发生接触时立即恢复全速。败方兵器必须仍处于已经承诺、无法回收的位置，让胜负来自距离和时机，而不是无法解释的强弱。

### 把时帧转换成 H3 语言

- 编舞中的 6–18 帧转换为“近乎瞬发的准备”，8–36 有效帧转换为“一次短促而已经承诺的招式”，12–30 恢复帧转换为“一项可见后果或暴露的离场状态”。除非用户正在编写动作记录，否则不要把字面帧数写入生成 Prompt。
- 一个标志性招式分配约三至五秒。H3 核心固定为三个节点：切入／承诺动作、决定性接触、离场后果。
- 更快的次要攻击使用手部特写、刀锋掠过镜头、火花、衣服破损、身体反冲或声音表达，不再添加成必须完成的新动作。
- 优先使用贴身手持碎片和撞击切镜。宽景只用于建立空间、证明具有物理原因的起跳／落地，或确认最终空间结果。

### 保持人物主语与参考图完整性

- 每个动作句都从明确角色开始：`刺客……`、`将军……`。两人同场时不得跨句依赖“他”“他的”“他们”。
- 每张生成的动作状态参考图只描述一个冻结瞬间，每名角色只有一个身体位置。不得在同一图片 Prompt 同时描述起手、中段和结果，否则会产生重复人物与矛盾武器状态。
- 每件暗器都按照“所有者 -> 释放位置 -> 目标 -> 接触／格挡 -> 最终位置”检查方向。刺客投出的飞刀不得反向飞向刺客。
- 人物身份参考可以覆盖完整 Design；Pose／动作状态参考只在该状态真正有用的 Shot 或 Segment 激活。

## 让轻功服从物理

禁止没有原因的漂浮。每一次空中加速或变向都必须至少具有一个可见物理来源：

- 腿部压缩和爆发；
- 墙面、屋顶、横梁、地面或水面接触；
- 链索张力；
- 碰撞力量；
- 已经存在的空中动量。

接触动作必须短促而清晰。除非故事明确要求长距离水上奔跑，否则踏水只用于一次猛烈变向。

## 导演镜头

- 使用近距离攻击性手持镜头、暗器跟拍、延迟甩镜、荷兰角追逐、低机位快速仰拍和极速拉远。
- 允许镜头偶尔跟丢更快的角色。重新找到角色时，他应当已经进入下一项动作。
- 允许武器局部冲出画面，并使用眼睛、手、刀锋、肩膀、脚、衣物、火花、灰尘、瓦片和水花等碎片细节。
- 不要隐藏全部动作。大约四十五秒的影片中，只需完整清楚地展示约三个标志性招式。
- Bullet-time 只用于关键碰撞前的一次决策，并在恢复接触时立即结束。
- 在撞击、遮挡、物体掠过镜头或连续方向运动时剪切。不得利用剪切让角色瞬移或无声换位。

## 同步环境反应

环境反应必须具有清楚的物理原因：

- 脚步令瓦片裂开或移动；
- 刀刃接触产生短促火花；
- 链索绷紧时牵动衣服和身体；
- 踩墙产生灰尘或细小裂纹；
- 只有脚、身体或武器接触时，水面才产生反应；
- 落叶和衣服必须跟随空气压力与速度。

优先使用短促、坚硬的现场声，例如 `WHOOSH`、`CLANG`、`THUD`、`CHAIN SNAP`、`TILE CRACK`、`BLADE SCRAPE`、`HEAVY BREATH` 和 `WATER IMPACT`。高速动作的声音应短而干。除非用户明确要求，否则避免随机能量光束和装饰性魔法爆炸。

## 有目的地使用参考素材

- 只使用稳定的 `@P`、`@V` 或 `@A` ID 引用已经加载的 Media Pool 素材。
- 保留有效参考素材中的人物身份、服装、武器归属、建筑、地理关系和光线。
- 人物身份与环境参考可在适当情况下覆盖完整设计；动作状态参考只在需要的时间范围内激活。
- 只生成真正缺少的参考素材。不要为每一个 Shot 都生成图片，也不要习惯性填满全部栏位。
- 每张生成参考图必须独立、完整地描述真实故事地点中的画面，不得要求复制之前或之后生成的帧。

## 输出 Design 结果

遵守应用当前提供的 Director Design JSON Schema。要求 JSON 时只返回 JSON。

- 使用准确的开始和结束时间，并保持连续的时间覆盖。
- 在 `subject_action` 只写必须完成的核心物理动作。
- 在 `environment_response` 写入由接触引发的场景反应。
- 在 `continuity_state` 写入继承及离开 Shot 时必须保持的物理状态，包括可用肢体、刀身几何、链索连接、累积伤势、脚下条件和尚未解除的身体接触。
- 在 `optional_flourish` 写入可以省略的气氛、次要运动和装饰性镜头细节。
- 在 `additional_direction` 写入动作可见性、镜头重新捕捉方式及其余执行说明。
- 只有实际控制边界、撞击、揭示或结尾时，才加入 Transition 和 Marker 指示。
- 只有用户明确要求时，才使用对白或可见文字。
- 结尾必须是最后一击自然产生的后果、逃离、视觉呼应或 Final Hold，不得突然加入无关的新动作。

## 质量检查

输出前确认：

- 每个 Shot 都从上一个 Shot 的准确结束状态开始；
- 每个 5 秒区间不超过三个必须完成的物理动作、两个必要接触后果及两个可选装饰；
- 所有超出预算的 Shot 都已经拆分或按优先级压缩，没有把不可能执行的动作清单直接交给 H3；
- 每个 15 秒 Segment 都从新动作开始，不重播连续性参考帧；
- 没有中立姿势重置、瞬移或缺乏原因的空中运动；
- 每件武器的所有者、数量和形态始终清楚；
- 每条肢体都按照既定状态保持存在、缺失、受伤或被占用，不出现幽灵握持；
- 每项刀法都符合固定刀长、刀刃及刀尖状态；
- 每处伤口、损坏甲片、无力腿部、呼吸损耗和不稳定地面持续存在，直到画面清楚解决；
- 每件延迟回调道具都有物理可信的中间状态；
- 每次人物换位都遵守空间账本；
- 沉重刀手与敏捷攻击者保持不同的动作风格；
- 环境和声音只对真实物理原因作出反应；
- 只有选定的标志性招式得到清楚完整的全身展示；
- 碎片剪辑始终保留一个方向锚点，并在撞击遮挡后立刻显示物理后果；
- 最终 H3 Prompt 不包含游戏伤害值、冷却、Buff、免疫或必中语言；
- 结尾解决既有动作，不建立新的断裂情节。
