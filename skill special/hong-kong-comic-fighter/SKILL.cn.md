# 港漫强者格斗 H3 导演

本 Special Skill 与 Default H3 Prompt Writing 一起使用。严格保留用户指定的时长、比例、人物名称、图片顺序、招式、结局与语言。港漫图片是视觉事实证据，不代表要把漫画边框、网点、对白框和印刷文字复制进影片。

## 图片事实账本

先建立可编辑事实账本，优先级为：

`用户明确说明 > 图片实际像素 > 明确人物／画面对应 > 复杂漫画页的AI Enrich > BLIP Overview后备 > Skill默认`

多格港漫页是短BLIP摘要的弱项。如果已有AI Enrich，优先采用较完整的人物、场景与材质分析，再以BLIP作后备；两者都不能推翻图片像素或用户明确的人物对应。

从当前图片读取人物样貌、年龄、发型、身材、服装、伤势、招式归属、画面先后；同时读取地点、地形、建筑、天空、天气、时间、色调、光源，以及可被力量影响的岩石、沙尘、水、玻璃、混凝土、植物或其他可见材质。

P1／P2编号不等于S1／S2人物。一张港漫页可能只有一人、两人、多格画面或纯环境。必须结合用户给的名字与全部图片判断人物。文件名不能成为剧情或地点事实。

除非原图或用户明确要求，禁止加入九龙菜市场、城寨、擂台、道场、霓虹后巷、观众或其他预设场景。

## 漫画转真人关键帧

用户要求真人版而来源是漫画时：

1. 原始港漫图片只作 `analysis_only`，不要把边框、网点、对白框、速度线和印刷字送入H3作为最终画面参考。
2. Z-Image使用 `source_img2img` 生成最少数量的真人关键帧。每一张生成图（包括人物身份图）都必须记录一个已加载且有效的 `source_plate_media_id`、相同的 `derived_from_media_id`、`source_plate_mode=source_img2img` 与适用范围；自由Text-to-Image重画的人物或地点属于无效参考。
3. 保留原图人物、服装色块、姿势意图、地形、地平线、天气、光向和关键物件，只把漫画材质转换为真人皮肤、布料、岩石、尘土、金属、水体与真实镜头景深。
4. 每个Shot最多生成一个冻结动作状态，并复用人物／环境锚点；禁止机械地每五秒产图或生成大量近似画面。
5. 如果图片已经适合真人H3，直接复用，不强制重绘。

两名持续出现的格斗者最多各建立一张清楚的单人真人身份锚点，并从最清楚的来源画面推导。任何同时出现两人的生成图都只能是time_scoped动作状态参考，绝对不能当作单人identity_anchor，也不能附加 `exactly one visible person` 规则。

关键帧只能表现一个冻结瞬间与正确主角数量。禁止页框、对白框、印刷中文字、漫画网点、卡通脸、塑料3D感、重复身体和多余肢体。

## 紧凑战斗与动作因果

影片先用极短的“超级英雄压力登场”建立绝世强者气场，再立即进入接触。前0.75–1.25秒采用低机位近景：人物落地或压下重心，衣物与头发被压力掀动，原图可见的砂石升起，人物真实投影沿原地形扩大，摄影机迅速Whip Tilt到面部；对手此时已经在场，并在约1.25秒前发动第一轮攻防。这是冲击式现身，不是走路入场、风景空镜、Pose拼贴、瞬移或无原因爆炸。10–15秒建议五至六个连续动作Shot、约十至十二个Combat Beat；更长影片跨15秒Segment继续同一状态账本，不能重播开局。

### 从第一帧持续出现的世界级特效

高潮使用的炸裂效果不能等到第8秒才开始。自第一轮攻防的第一帧起，每个有效格斗Shot都必须保持持续、由原图产生的力量场：空气湍流、衣物与头发被掀动、原图已有的砂石不规则升起、主动肢体周围局部热浪／空间折射、受压高光边缘、真实投射阴影变化，以及跨切镜延续的尘土与风。每次真实接触都追加一次沿受力方向的压缩空气爆破和材质反馈；后续只逐步增加规模与气象影响，绝不能退回普通拳脚。生成的time-scoped动作参考图也必须带这套视觉契约；干净的人物身份锚点保持纯净。所有效果都要是附着人物与接触点的写实物理特效，禁止发光圆环、HUD、速度线、传送门、无原因背景火球或全画面卡通光环。

默认不创作人物聊天。用户明确提供的旁白与人物说话必须逐字保留；当Requirement要求Skill自动创作港漫旁白时，每15秒最多一条简短的第一人称或全知旁白，只负责建立决意、挑战或后果，不逐拳解释。招式呐喊保持短促。所有声音与文字都必须进入可编辑 `text_layers`，禁止藏进Shot Prompt。

每个完成的招牌招式建立一个简短中文招式名，放在可编辑 `on_screen_text` 层，并对齐招式接触或释放时刻。同一时间只准出现一个招式名，不能遮挡人脸，也不能让Z-Image或H3把文字直接画进参考图。Combat Beat不等于一个独立招式；以每个Shot真正完成的招式为标题，避免快速对拆变成满屏文字。

每个Beat严格遵循：

`重心／蓄力 → 爆发加速 → 攻击线路／抓握 → 防守／反击 → 接触或落空 → 受力形变 → 人物位移 → 环境反馈 → 下一动作触发`

每个Shot必须把人物位置、朝向、距离、速度、支撑高度、守势／抓握、优势、伤势、服装破损、招式蓄力和环境余波交给下一Shot。拒绝“快速交手”“激烈攻防”“举起拳头”“看着对手”“保持对峙”等模糊动作；必须写明攻击肢体或抓握点、线路、明确防守、接触／落空及造成的位移。禁止只放大静态漫画、自己防守自己、人物瞬移、复制、换装、身份交换或无过程改变地面上下位。

动作采用全速2倍节奏：每组蓄力、攻击／防守、接触和回收约0.45–0.65秒完成，并直接成为下一Beat的起势；提示词写成爆发式实时动作，不写成快进播放。禁止走路、中性重置、长时间蓄力、慢动作、子弹时间、冲击定格、Speed ramp、停顿受力、重复预备或只把静态Pose放大。

当用户明确要求摔投、倒置重摔或连续控制型擒拿终结技时，读取 [references/mythic-grappling-impact.md](references/mythic-grappling-impact.md)，采用其中不中断的抓握、身体控制、破坏传播与H3原生声音链；普通拳脚场景不能自动硬塞这套终结技。

用户要求灾难级高潮时，采用同一参考内的爆裂构图：极低机位近距离、清楚可读的倒置／控制关系、真实接触点深坑、前中后景三层碎片与两侧尘爆。只复制力量层级，不能复制示例图的寺庙、石柱、树木、旗帜或其他未在当前原图出现的地点元素。

## 世界级力量与背景因果链

强者力量必须影响世界，但不能取代原图世界。每次按五段接力：

1. **压力起势：**人物蓄力先影响衣物、空气和原图确实存在的松散颗粒。
2. **接触压缩：**真实接触点出现局部热浪式折射、定向光脉冲或压力锥；禁止变成传送门、发光圆环或全画面扭曲。
3. **材质传播：**力量接触后才影响原图里的岩石、沙土、水、玻璃、混凝土或树木，并沿记录的受力方向碎裂、飞散、喷溅或弯曲。
4. **气象升级：**较远的风沙、烟尘、云层、雨水或水面延迟响应且能量递减；天气因为压力波到达才变得狂暴。
5. **后果持续：**裂纹、碎石、沙尘、水波、风向和损坏物体必须延续至后续Shot，不能切镜后自动复原。

每个Beat只使用一个主要材质反馈与最多一个较远气象反馈。每个完整招式都必须达到无敌绝世强者的世界级规模：蓄力带起原图已有石块、沙层与松散物；接触产生一次定向压缩空气爆破与局部空间透镜扭曲；被接触的材质再沿受力方向碎裂或爆开；风沙墙、狂风、云层剪切、雨、烟尘、光线和真实投射阴影只能随后升级。爆炸只能是力量抵达可见材质后的局部压力／碎片爆发；禁止无原因背景火球、提前破坏、整栋建筑或世界毁灭。空间扭曲期间仍须保留地形轮廓、建筑几何、地平线、天空与原图色调，让观众能认出来源场景。

用户要求太阳招式时，把其中一个高潮攻防留给太阳系招式：白金色紧凑日冕只包围发力肢体或真实接触点，带有等离子丝、热浪折射、自然曝光适应、暖色反射与扫过原场景的长硬边动态阴影。这是写实超级英雄级能量，不是天空里新增一颗太阳、传送门、能量圆环、卡通光环或替换背景。

## 运镜

每个Shot只有一个由格斗动作触发的实体运镜。默认摄影机围绕两名人物共同中点做近距离实体FPV平移，以遮挡变化、背景视差和视点变化证明真实移动；按动作原因交替方向与高度，禁止每个Shot都使用同一个顺时针／正面弧线。禁止原地旋转360度、Zoom-out、Pull-back、远离战斗或连续正面机位。

10–15秒内至少经过正面三分之四、侧面、后方三分之四、另一侧与另一正面三分之四。至少70%使用Close-up、Extreme close-up或Eye-level close；只有需要证明世界级环境反馈时可使用不超过1秒的Wide。使用Hard cut、Match-on-action和Sound bridge，每个Cut继承动作方向、画面方位、摄影机区域和环境余波。

## 现场声、JSON与素材映射

默认只使用H3原生现场声。每个完成招式必须按画面原因形成一条同步声音链：踏地与衣物崩紧→高速肢体破风→一次清楚的身体／格挡／接触瞬态→压缩空气爆裂→延迟出现原图材质碎裂、砂石散落、地层低频震动、狂风或天气回应。太阳系招式在真实发力／接触点加入紧凑日冕或等离子蓄能声与一次热压释放声，禁止循环科幻音。声音必须保持现场距离与室外声学，每个原因只出现一次。除非Timeline明确要求，不自动配乐，不复制参考音频对白。用户要求的港漫旁白必须来自Timeline语音层，不能变成Shot Prompt里自动冒出的录音棚旁白。

输出一个有效Director Design JSON；Shot完整覆盖准确时长并落在0.5秒网格。分开 `subject_action`、`environment_response`、`continuity_state`、`optional_flourish` 和 `additional_direction`。保留可编辑的动作与环境因果字段。

真人模式下，原始港漫图只作分析／控制证据；真人身份与环境锚点可在相关Shot复用，动作状态图只属于对应Shot。每个Segment只装入当时有效的参考。Virtual Media Pool不受总数限制，但严禁请求冗余图片。

## 最终收尾与验收

最后招式以全速完成接触、回收、受力传播与位移；最后0.75–1.00秒两人落到清楚支撑状态，摄影机稳定到三分之四构图，原图环境的风沙／天气余波自然延续。禁止新攻击、重播、走开、Zoom-out或把冲击本身冻结。

验收必须确认：真人／漫画模式没有意外混合；人物与招式归属稳定；P1/P2不被机械绑定为两个人；前0.75–1.25秒的超级英雄压力登场没有被裁掉；每个Beat因果完整且状态接力；运镜由动作触发；世界反馈从接触点沿正确方向传到原图可见材质；每个完整招式有一个不重叠、可编辑的中文招式名；每个完成招式都有蓄力、破风、接触、压力爆裂与延迟环境反馈的H3原生同步声音链；港漫旁白稀疏、逐字且可编辑；太阳能量、超级英雄光效与动态阴影都绑定真实招式原因；空间扭曲局部且环境仍可识别；没有固定市场、无关观众、随机爆炸、发光圆环、提前破坏或背景自我修复；真人关键帧数量最少且按时间使用；最终Shot稳定收束，所有文字保持可编辑。
