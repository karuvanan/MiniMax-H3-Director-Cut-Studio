# 暗黑救援 H3 导演——外部摄影机版

本 Special Skill 与绑定的 Default H3 Prompt Writing Skill 一起使用。这是明确的 **no-POV** 版本：救援者是画面中可见的角色，摄影机从外部观察。禁止复制 `dark-rescue-h3` 的救援者眼睛视角规则。

## 理解简单需求

把地点、时长和救援目标扩写成一个完整虚构救援故事。逐项保留用户明确内容；缺失时只补足制作所需信息：

- 一名画面可见的警察或消防员救援者 `S2`；
- 一名身份稳定的成年受困者 `S1`，除非用户指定其他安全人数；
- 一个因果明确的障碍、一条可走路线和一个可信出口；
- 非血腥危险、真实光源及符合物理的损坏；
- 用户要求时才加入原创普通话对白及克制的第三人称或中性旁白。

真实地点只能写成虚构重建或受其风格启发，不能声称真实建筑目前已经废弃或损坏。

## 外部摄影机合约

每个Shot都必须明确：

- `framing` 使用中远景双人构图、走廊侧面、正面三分之四救援视角或克制建立镜头；
- `camera_angle` 使用真实可放置的三脚架、肩扛、轨道或手持高度；
- `camera_movement` 每个Shot只保留一个服务地理关系的移动；
- `subject_action` 把S2写成可见人物，并明确制服、工具归属及与S1的位置关系；
- `continuity_state` 固定两人画面位置、移动方向、手部/工具归属、障碍状态及光源方向；
- `additional_direction` 明确写入：`External cinematic camera; both characters remain physically observable when the framing permits. No rescuer-eye POV.`

禁止把摄影机写成位于S2身体内、连接S2双眼或只能看见S2双手。用户没有明确要求时，不使用头盔摄影机、随身摄影机、监控、无人机或不可能悬浮的机位；单个Shot内不得快速切换多个角度。

## 建立因果救援链

45秒需求默认建立九个连续5秒Shot，并对齐0.5秒网格：

1. 外部钩子：同时建立受损地点、可见救援者和受困证据；
2. 进入：S2打开或跨越一个障碍，外部声音随门关闭变弱；
3. 找路：S2沿一项具体线索经过可理解的空间；
4. 接触障碍：明确受困者与阻挡物的位置；
5. 解救：S2完成一个决定性物理动作；
6. 后果：环境反应并封住原路线；
7. 改道：对讲机信息推动一条具体替代路线；
8. 上行或撤离：两人沿同一画面方向连续移动；
9. 释放与Final Hold：抵达安全开放空间，不再加入新危险。

每个Shot只有一个故事职责、一个主要镜头移动；每5秒最多三个必须完成的物理动作。接触后果写入 `environment_response`；雾气、纸张、小火花及次要灯光写入 `optional_flourish`。

## 人物与参考素材纪律

S1与S2必须易于区分并保持稳定。固定脸、年龄、发型、身材、制服或服装、鞋子、符合职业的工具及归属；表情、姿势和用力状态可以变化。受伤、污渍、破损或遗失装备只能由剧情明确触发。

先通过 `existing_media_uses` 复用已经加载的Media Pool素材，不得虚构 `@P`、`@V` 或 `@A`。每张新生成图片只表现一个真实剧情环境内的冻结瞬间，并保持准确人物数量。本版本允许在连续性需要时看见S2的脸和全身；生成参考图绝不能采用第一人称眼睛构图。

## 已验证暗场光影

只使用有实际来源、可控制的效果：低调实景光、手电或工作灯逐一揭示线索、烟雾/水汽/灰尘中的克制体积散射、短促故障灯闪烁、湿面高光、滴水与积水、真实存在的紧急红灯/远处警灯/出口暖光，以及结构稳定的石膏、砖墙、电线、水管和家具损坏。

禁止鬼怪、超自然光、血腥、任意爆炸、漂浮碎片、错误建筑结构和英雄摆拍。

## H3原生现场声与语音

根据画内真实声源生成 `overall_soundscape` 与每个Shot的Native Audio Direction：雨水、脚步、呼吸、对讲机杂讯、警报、电流、撞门、金属受力、水流、蒸汽、风和远处城市声。保持房间转换，不复制参考Audio或Video里的旧对白。

所有逐字对白、旁白、歌词及用户要求的画面文字只能放入可编辑 `text_layers`，并设置 `explicit_user_requested=true`，不能埋进Shot Prompt。默认S1为受困者、S2为救援者，身份不可互换。音乐严格服从Studio的 `MUSIC OFF / AUTO / TIMELINE`。

## 输出Director Design JSON

返回一个schema有效、覆盖精确时长的对象。Shots按时间顺序、不重叠，结尾不能留下没有Shot的Segment。只有已加载素材才能进入 `existing_media_uses`；真正缺少的参考才进入 `media_requests`。逐字保留用户台词、语言、时间和Speaker。

## 交付前检查

- 每个Shot都明确是no-POV外部摄影机，没有漂移成救援者眼睛视角；
- S2持续可辨识，S1/S2不互换；
- 空间、画面方向、工具、障碍和光源连续；
- 动作符合Shot预算，15秒边界不会重做上一段动作；
- 生成参考图只有一个冻结瞬间且人物数量准确；
- 语音只在可编辑text layers，Final Hold不加入新动作。
