帮我创作一段 12 秒、16:9、电影级写实城市航拍视频。`@P1` 是开场场景锚点，`@P2` 是我绘制的飞行轨迹控制图；如果我另外加载并选择 P3、P4、P5 等场景图，把它们按 Picture 编号作为后续场景锚点。无人机按照控制图所表达的起点、转弯顺序、曲线方向与终点连续飞行，同时围绕当前场景中最清楚的中央地标完成一次平稳的 360 度环绕偏航。开场必须匹配 `@P1`；运动结束后摄影机平滑返回 P1 的精确原始机位与构图，最后 1 秒直接冻结并展示未被重绘的 P1 原图。只需要真实的高空风声与远处城市底噪，不要对白；音乐跟随主页 MUSIC 设定。

你可以修改上面的时长、比例、地点、目标地标、速度和旋转模式。以下为固定制作合约，不得删除或弱化：

## 1. 输入素材职责

- `@P1`：必填开场视觉锚点。只有 P1/P2 时，它是完整影片的场景母版；存在后续用户场景图时，它只负责第一个关键帧区间。保持其地点、建筑与道路布局、地标相对位置、天气、时间、光线方向与强度、色彩、调色、曝光、对比度、空气透视、镜头高度、焦段质感和特殊视觉效果。
- `@P2`：仅供 Design 分析的非视觉控制数据。只提取起点、重要转弯、曲线方向、终点和运动节奏，然后转换成抽象的摄影机运动参数。
- 缺少真实加载的 `@P1` 或 `@P2` 时，停止并清楚提示缺少哪一项，不得虚构素材编号。

输出 Director Design JSON 时，`existing_media_uses` 必须同时登记：

- P1：`media_type="image"`、`usage="h3_reference"`。只有 P1/P2 时使用 `reuse_policy="whole_design"`；存在 P3 或更后的用户场景锚点时，改用互不重叠的 `time_scoped` 区间。
- P2：`media_type="image"`、`usage="analysis_only"`、`reuse_policy="whole_design"`，覆盖完整时长。

P2 只保留在 Virtual Media Pool 的分析资料中，不得放入 Timeline，不得占用 Segment 的实体 Picture 槽，不得进入 ComfyUI 上传清单，不得成为 H3／Z-Image 的图片、首帧、尾帧、构图、风格、场景或人物身份参考。

## 2. 航线转换与 Shot 设计

- 将控制轨迹简化成 3–6 个有意义的规划节点；保留每个主要弯位，不能把曲线拉直、跳过转弯或改变起终点。
- 规划阶段可以使用 WP 编号和归一化画面坐标；真正写入 Shot 与最终 H3 Prompt 时，必须将它们翻译成可拍摄的物理运动，例如“从画面左下方平稳前进，缓慢升高，沿宽弧向左绕过中央高楼，再向右收回至天际线”。
- 最终可渲染字段不得出现 P2 标签、WP 标签、坐标、控制图外观或任何可能被理解成画面图层的导航术语。
- 360 度只完成一次。环绕角度应按总路程连续分配，保持稳定环绕半径、水平线、真实惯性、自然加速与减速，禁止突然倒转、瞬移、穿楼或撞到建筑、树木、电缆、车辆和行人。
- 12 秒默认规划为 3 个连续 Shot；其他时长按每 Shot 约 4–6 秒自动调整。Shot 必须按时间顺序、无重叠、无空隙，并覆盖完整影片时长。
- 每个 Shot 只采用一个主要镜头运动，并填写 must-complete subject action、environment response、incoming continuity state、outgoing continuity state 与 optional flourish。核心飞行动作必须先完成，装饰效果可优先省略。

## 3. 场景关键帧链

- 只有 P1/P2 时，保持单一场景，不强行生成额外关键帧。
- 如果存在后续用户场景图，按 P1 → P3 → P4 → P5 的实际已选顺序建立关键帧链，跳过 analysis-only 的 P2，也跳过未被用户选择的图片。
- 每个用户场景锚点只负责一个互不重叠的时间区间。后一张 Picture 不得提前进入前一场景的 H3 请求，避免改变 P1 的建筑、光线、构图或色彩。
- Studio 必须在每个关键帧边界建立独立的原生 H3 Job；下一段只接收上一段最后 24 个无声视频帧作为运动连续性，不把上一段音频当作参考。
- 不得把旧的 AI 自动收尾图当作新的用户场景锚点，除非用户已经替换或明确选择它。

## 4. P1 不可变尾帧规则

- 无论只有 P1/P2 还是存在多场景关键帧链，都只能建立一张链尾尾帧，不得机械地为每个 Shot 生成图片。请求 ID 使用 `auto_terminal_keyframe_after_<最后用户锚点>`。
- 尾帧必须以已加载的 P1 本地像素为不可变 Scene Plate，而不是交给 Z-Image／T2I 重新想象。设置 `source_plate_media_id="P1"`、`source_plate_mode="immutable_copy"`、`source_plate_effect_profile="preserve_existing"`、`immutable_scene_plate=true`、`final_hold_seconds=1.0`。请求保持未命名且不填写 `preferred_media_id`，由 Studio 分配真正空置的下一个编号。
- 完全保持 P1 的摄影机位置、高度、焦段、构图、水平线、地标大小与间距、天际线几何、道路、建筑、天气、色调、曝光、对比度和原有城市灯光。不得移动、旋转、升高、重新取景、重设计、复制、扭曲、移除或替换任何元素；不得自行增加新特效。
- 城市、建筑、道路、天际线及其他纯环境补图必须是 environment-only reference：不得设置 `identity_anchor=true`，不得加入人物身份连续性合约，不得要求出现人脸、人物、巨型人物、雕像式人像或楼顶人物。
- 普通版尾帧不得改变摄影机位置、取景、视角或运动阶段，也不得改变城市结构、地标、天气、时段、照明、色调、曝光或镜头质感。
- 所有补图都是冻结静态环境画面。从普通Prompt与subject_keywords删除360度、orbit、orbital yaw、圆形、轨迹、路线及航点运动描述，只保留建筑、天气、光线、色彩、曝光、镜头与冻结机位；不得复制P2的标签、颜色、线条、箭头、标记、文字、界面或图层外观。正向提示词准确追加：`The drone flight path is implied only through camera motion and must never be visible in the image. No orbit ring, no circular light trail, no glowing ellipse, no trajectory line, no HUD, no graphic overlay around the towers.` 专用Z-Image负面提示词使用：`visible flight path, orbit ring, circular light trail, glowing ellipse, light ribbon, trajectory line, energy ring, HUD overlay, graphic circle, neon loop around buildings`。这份负面词表不得进入最终H3视频Prompt。

## 5. 最终 H3 Prompt 合约

- 最终视觉参考只允许使用当前关键帧区间对应的一个用户场景锚点、链尾的合格自动收尾图，以及系统提供的上一段 24 帧无声运动上下文；绝不包含 P2，也不得提前加载未来场景图。
- Special Skill 的名称、简介与分析说明不是渲染内容，不得逐字复制到 H3 Prompt。
- 最终提示词只描述城市实景、摄影机的连续位移、升降、转弯、环绕目标、速度变化、视差、惯性、最终构图与停留状态。
- 结尾使用正向画面约束：写实城市画面保持干净无遮挡，所有规划控制均位于画外；水平线稳定，城市几何一致，航拍视差与惯性连续可信。
- 不生成地图、图解、导航界面、屏幕覆盖层或任何可见的规划控制表现。
- 环境声属于画面中的真实声源：连续高空风声、远处城市低频底噪和符合距离的交通声。不要额外对白、播音员旁白或录音棚声音。非画内音乐严格服从主页 `MUSIC: OFF / AUTO / TIMELINE` 选择。

## 6. Apply 前自检

1. 只有单场景时 P1 是全程母版；多场景时 P1 与后续用户图片形成互不重叠的 time-scoped 锚点链。P2 的 usage 精确为 `analysis_only`。
2. P2 没有 Timeline Clip、实体 Picture 映射、上传 Loader 或生成图片父级关系。
3. 所有 Shot 覆盖完整时长，时间连续且不重叠。
4. 可渲染 Shot 与 H3 Prompt 已把规划节点转换成自然摄影机运动，不含 P2／WP／坐标或控制图外观描述。
5. 只存在一张 P1 不可变尾帧；它没有人物身份锚点、没有新增人物、未经纯文字T2I重绘，输出像素来自P1。
6. 只执行一次 360 度旋转；之后回到P1精确原构图，最终1秒直接冻结P1，没有重复动作或突然跳变。
7. 最终 H3 Prompt 使用当前 Segment 动态映射后的 Picture 编号，不使用 Media Pool 的固定物理槽假设。
8. 当前关键帧 Job 没有加载未来 Picture；边界衔接只使用上一段最后 24 个无声视频帧。
9. 每张自动参考图已经移除360度环绕／yaw／trajectory摄影机运动词，包含精确Clean Frame句及专用负面词表；最终H3 Prompt不包含这份负面词表。
