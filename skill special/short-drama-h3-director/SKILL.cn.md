# 短剧 H3 导演

本 Special Skill 必须与绑定的 Default H3 Prompt Writing Skill 同时使用。Special 负责戏剧结构与制作规划，Default 负责官方 MiniMax H3 Ref2VA 结构及参考素材语法。

## 定义一个可执行制作单元

一个 Studio Project 对应一集短剧或一个有明确边界的制作单元。保留用户指定的时长、比例、语言、类型、观众、平台、地点、人物、预算、参考素材与交付形式。

遇到多集需求时，只把全剧前提与集间推进作为精简背景，再完整执行用户指定的当前一集。除非用户明确要求，不把数集完整剧情压进一条短 Timeline。

创作简报至少确定：

- 类型及观众承诺；
- 主角当下可见目标；
- 阻力、风险及失败代价；
- 关系压力或隐藏信息；
- 开场钩子、升级、反转、情绪落点及集尾钩子；
- 制作限制和精确交付内容。

只询问会实质改变结果的缺漏，其他部分采用并标明合理假设。

## 建立因果戏剧

每个场景和 Shot 必须改变信息、关系、目标、风险或情绪中的至少一项。禁止只重复故事前提。

使用以下因果链：

1. 一个可见触发事件改变当前局面。
2. 人物追求眼前目标。
3. 另一人物、物件、规则、期限或隐藏事实形成阻力。
4. 人物作出选择并造成可见后果。
5. 后果推动下一个 Shot，不能重置场面。

反转之前必须埋下证据；观众回看前段时应觉得反转更合理。禁止为了制造惊讶而突然加入没有铺垫的人物、物件、能力或自白。

集尾必须留下新问题、不可逆代价、关系改变或即时威胁。钩子要推进故事，不能只是任意中断。

## 锁定人物与关系连续性

写 Shot 前固定：

- 人物数量、身份、外貌、服装及可见道具；
- 每个人知道什么、当前目标及情绪压力；
- 每场开始和结束时的关系状态；
- 关键物件由谁拥有、看见、听见、给予、接收或隐藏；
- 地点地理及不同空间之间的可见移动路线。

没有可见事件、发现、威胁或选择时，不能突然改变人物动机。使用动作、反应、回避、迟疑、视线、距离、道具处理或对白表现内心变化，不要只靠解释性旁白。

## 逐字保护用户对白

用户明确提供 Dialogue、Voice-over、Lyrics 或 On-screen Text 时，逐字保留内容、语言及时间范围。禁止改写、总结、重复、翻译、漏字或换给另一位说话者。

所有声音和画面文字必须进入 `text_layers`，不能只藏在 `subject_action`、`creative_brief` 或 Shot Prompt 中。

- `dialogue`：画面内人物对白；除非用户指定，女性使用 S1，男性使用 S2。
- `voice_over`：不要求画面口型的旁白或内心声。
- `lyrics`：用户明确提供的歌词。
- `on_screen_text`：必须在画面中显示的文字。

用户明确要求的内容设为 `explicit_user_requested=true`，并保留语言、Delivery 与 Lip Sync。对白必须具有行动性：追问、试探、回避、施压、揭露或反应。能用动作和潜台词表达的信息，不使用长段背景说明。

逐字内容放不进原时间范围时，保留全部文字并要求自然加快语速或扩展时间，不能通过删字解决。

## 转换成 Director Design JSON

只返回符合 Schema 的 Director Design JSON，不输出剧本 Markdown。所有 Shot 使用 0.5 秒网格，按时间顺序排列、互不重叠并覆盖完整时长。

每个 Shot 必须包含：

- `framing`：清楚呈现戏剧信息的构图；
- `camera_angle`：表现当下权力或情绪关系；
- `camera_movement`：一种主要镜头运动，表演更重要时保持稳定；
- `subject_action`：必须完成的可见因果动作；
- `environment_response`：只保留证明因果所需的接触／事件反应；
- `continuity_state`：进入和离开时的姿势、视线、道具归属、屏幕方向、情绪及未完成动作；
- `optional_flourish`：可以省略的气氛或次要行为；
- `additional_direction`：表演、潜台词、节奏及参考素材用法。

每五秒最多三个必须完成动作、两个必要后果及两个装饰动作。时间足够时把超载内容拆成连续小 Shot；否则优先保留触发、关键选择、后果和离开状态，再舍弃装饰。

反应镜头只有在反应改变意义或决定时才保留。没有新增信息时，不重复哭泣、凝视、走路、看手机或对峙。

## 规划视觉语言

9:16 竖屏短剧要确保关键面孔、手部、手机信息、证据或人物关系轴在单一竖画面中清楚可见，避免线索小到无法阅读的过宽场面。

镜头语言服务戏剧：

- 表演与潜台词使用稳定或克制的镜头；
- 发现、压力或不可逆选择使用 Push-in；
- 孤立、暴露或空间改变使用 Pull-back；
- 即时危险或不稳定感使用受控手持；
- 只有故事关键证据才使用 Insert／Macro；
- Cutaway 必须揭露信息，不能只是装饰。

剪接前后保持屏幕方向、视线、道具位置和室内地理；不能用转场掩盖连续性错误。

## 规划参考素材

生成新素材前先检查 Media Pool 证据。符合需求的素材通过 `existing_media_uses` 及稳定 `@P / @V / @A` ID 复用，禁止虚构空 ID 或替换已经满足需求的用户素材。

只有真正缺少人物身份、服装、地点、证据物件、情绪状态或边界构图时才建立 `media_requests`。不要机械地每个 Shot 生成一张图片。

每张生成图必须是完整独立的 Prompt，只表现故事真实环境中的一个冻结瞬间，保持人物／道具数量和归属准确；时间范围素材不能使用空白棚拍背景。

## 设计对白、环境声及音乐

对白要像在画面地点现场收音：自然呼吸、对话停顿、与镜头距离一致的空间感、轻微环境渗入及符合地点的反射。画面人物对白不能要求干燥的播音棚声音。

适用时规划三层现场声音：

1. 连续地点环境底噪；
2. 与画面接触精确同步的 Foley／单次音效；
3. 前景对白。

非叙事音乐保持为独立层：对白时压低，空隙和转场时上升，支持压力或释放但不能取代表演。

## 转场与 Final Hold

大部分戏剧对话使用直接 Cut。只有为了保持方向或跨边界传递信息时才使用 Match Action、Sound Bridge、遮挡或有动机的 Insert。

最后一帧前建立 Final Hold Marker。稳定最后 Shot 的离开状态与集尾钩子，不加入新的多步动作；在 Hold 中保留可读面孔、证据、威胁或已经改变的关系。

## 交付前验证

- 时长完整覆盖，没有 Shot 缺口或重叠。
- 每场改变信息、关系、目标、风险或情绪。
- 每次反转都有前段可见或可听线索。
- 人物知识、动机、服装、道具和地理保持连续。
- 用户 `text_layers` 逐字保留、只出现一次并分配给正确 Speaker。
- 先复用 Media Pool，再请求新参考素材。
- Shot 动作预算可执行，Final Hold 没有新动作。
- Constraints 明确身份、连续状态和核心动作优先于装饰。
- 输出是可交给绑定 Default H3 Skill 的有效 Studio Design JSON。
