# Comic Talk Show H3

本Special Skill与Default H3 Prompt Writing一起使用。必须加载`@P1`；P1是全片人物、构图、服装、地点和原始视觉媒介的最高事实。

## Design前先分析P1

规划Shot和台词之前，先按照当前P1视觉证据建立人物账本。只计算完整、清晰、属于主要群像的前景人物；忽略画面边缘残缺身体、背景路人、照片中的照片、反射、雕像、人体模型和重复形象。严禁固定假设五个人。

按照P1开场构图从左到右建立稳定Speaker：最左边完整主要人物为`S1`，下一人为`S2`，依次建立`S3、S4……SN`，直到所有完整主要人物各自拥有唯一ID。

每个ID记录P1确定的画面位置、脸孔、年龄感、发型、身形、完整服装、鞋子和配饰。镜头平移、重新构图或切近景时编号不得改变；禁止按性别重新编号。

如果P1证据不足以确认某项，只需中性保留原图，不得创造替代演员。BLIP与AI Enrich只是描述证据，不能覆盖P1像素事实。

## 锁定原始视觉媒介

严格跟随P1实际媒介：照片保持照片，2D漫画保持原线条和上色语言，3D保持3D，插画保持插画。“自然表演”只描述动作，不代表可以把漫画真人化、真人卡通化或更换画风。

除非用户明确要求新地点，否则保留P1的地点、色调、光线逻辑、物件布局与群像身份，禁止改造成通用年轻真人演员。

## 素材规则

把P1登记为覆盖最终完整Timeline的`whole_design h3_reference`，每个Segment都必须保留P1。

普通P1 Talk Show不得自由生成演员、肖像、动作姿势或新群像图；图片`media_requests`必须为空。严禁生成P2-P9陌生人物来代表不同Speaker。近景、表情和反应由H3根据P1及Shot指令完成。

只有用户明确要求新环境时，才可以考虑完全不含主要人物或替代人物的环境图；否则继续保留P1背景。

## 动态适配人数

- 一人：对镜单口喜剧；
- 两人：铺垫、反驳与反转；
- 三人：开题、升级与收尾；
- 四人或以上：每人一个主段落，其他人做无声反应，最后群体收梗。

建立一个开场群像Shot、每位完整主要人物各一个清晰发言Beat，以及一个最终群体笑点Shot。时长不足时可以合并镜头，但除非用户另有要求，每位主要人物仍必须获得一次可明确辨认的发言。

先计算语音预算再固定边界。以用户明确时长为目标；优先缩短AI创作对白和删除重复铺垫，不得为了保留冗长AI台词而把45秒悄悄延长。至少保留15%时间给无对白反应、环境声、运镜和结尾。只有用户逐字指定而且无法自然容纳的台词才允许延长。

## 对白与脸孔绑定

每句最终台词必须建立为独立、可编辑的`text_layers`，使用动态`S1...SN`，设置`explicit_user_requested=true`，不得把台词埋入Shot Prompt。

每条自动生成的Dialogue Text Layer必须在预计台词说完时结束，不得让一句短对白占满整个摄影Shot。释放出来的Shot尾段只用于闭嘴反应、环境声与画面同步Foley。没有Dialogue Text Layer重叠的区间，不得在Shot描述中写入`speaks`、`says`、`after the line`、`before the next line`或同类说话状态。

每位主要人物拥有独立Speaker和Dialogue Text Layer。非重叠对白期间，只有被指定的P1人物移动嘴唇和下颚；其他人物必须闭嘴，通过眼神、眉毛、转头、姿势、憋笑或小动作做无声反应。Voice-over不得驱动任何人物嘴形。

每个Dialogue或Voice-over Text Layer都必须设置结构化`voice_gender`：`male`、`female`或`auto`。只有P1中该Speaker的实际人物身份或用户明确指示足够清楚时才使用`male`或`female`；证据不明确时使用`auto`。声线性别属于每条语音事件，不属于`S1…SN`编号，选定值必须原样传入H3 Native或外部TTS。

每一个已经创作的Dialogue或Voice-over事件都必须拥有自己的可见Timeline轨道（`D1、D2、D3……`或对应旁白轨道）；即使同一人物稍后再次发言，也不得为了节省轨道而复用上一条。这里的轨道是归属与编辑通道，不代表H3原生混合音频已经拆成独立声音Stem。

普通轮流说话时，`overlap_policy=auto`按顺序处理，并在上一句结束后至少保留1.0秒闭嘴释放区，供听者反应、环境声和非人声Foley继续，下一句才能开始。只有剧本明确要求打断、齐声或同时回应时才可使用`overlap`，而且必须位于不同轨道；禁止仅因时间排得太紧而推断为重叠对白。

每条Dialogue Text Layer到达结束时间时，当前Speaker必须立即恢复闭嘴或自然非发声嘴形。下一条授权Text Layer开始前，所有主角保持人声静默：禁止即兴接话、重复笑点、翻译、抢答、有声笑、填充音节、耳语或背景交谈；现场环境声及非人声Foley正常持续。

默认`overlap_policy=auto`。只有明确的打断、齐声或同时反应才使用`overlap`并放入不同音轨。禁止因为所有人来自同一张P1而把多人合并成一个Speaker。

声线跟随P1人物与表演说明，不得规定奇数Speaker一定女性、偶数Speaker一定男性。

## 喜剧与运镜

笑点必须友好、来自人物性格和因果节奏：视觉铺垫、一个人的台词或动作、听者反应、笑点落地。除非用户要求，禁止羞辱、恶意或无关受伤闹剧。

开场接近P1原群像构图。通过平移、短距离横移、重新构图和轻微推近突出发言者，并尽量保留至少一名听者的反应。切近景不得换人。结尾回到清晰群像完成最终包袱。

每个Shot只使用一个主要运镜；人物左右顺序、视线、坐站关系、道具和背景几何必须连续。最后0.5至1.0秒为稳定Final Hold，不得开始新台词或动作。

## 原生声音

对白必须成为符合P1可见空间、距离与方位的现场原生声音。对白期间持续保留环境底噪和画面同步Foley；只有非叙事音乐可以降低，环境声和Foley不得消失。禁止新增无来源对白。

## Apply前检查

- P1存在并覆盖最终完整时长；
- 人数来自P1完整主要人物，不是固定模板数字；
- 从左到右人物账本稳定，每个Speaker只对应一个P1人物；
- 每位主要人物至少有一次可明确归属的主发言；
- 每句对白只出现一次并可编辑；
- 每条语音Text Layer都有明确`voice_gender`，与所绑定的P1人物一致，绝不按Speaker奇偶数猜测；
- 每个语音事件拥有独立可见Timeline轨道，顺序对白之间保留1.0秒无对白释放区；
- 非授权重叠时只有指定Speaker对嘴；
- 没有自动生成图片引入或替换人物；
- P1画风、脸孔、服装、色调与地点保持最高权威；
- Shot完整覆盖最终时长，没有空白或重叠；
- 最终群体笑点完成后进入稳定Final Hold。
