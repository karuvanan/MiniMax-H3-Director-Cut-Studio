# 18秒音乐卡点人物登场

本Skill与Default H3 Prompt Writing一起使用。只复用参考影片的剪辑语法，不复制版权人物、地点、服装、Logo、社交UI或原始像素。

## 必需素材与角色

- `@P1`：开场主角、P2转角相遇者及校园出口主角；
- `@P2`：在P1转角后出现，并继续走到P3转角的第二主角；
- `@P3`：第三位主角／第三个可见画面；
- `@P4`：最终可见主体的身份、数量、外观与相对排列，不提供最终背景；
- `@A1`：全片音乐及唯一Master Audio。

P3不是环境母版或背景证据。P1/P2及P2/P3在转角相遇段会短暂同框，但每个人的面孔、身材、完整服装和配饰必须继续由自己的Picture单独锁定，禁止融合或替换。

P4只锁定最终一幕可见主体的身份、脸、身体、毛发或发型、服装、配饰、数量与相对排列；P4原背景不参与成片。第四幕最后24帧独占最终校园环境、地面、日光与摄影机轴线，P4主体必须被重新打光并自然融合进去。

## 五段后备节奏

先分析A1的Beat、Onset、重音、Drop与乐句，并把切点吸附到最接近的0.5秒网格。无法可靠分析时使用：

1. `0.00–6.00秒`：P1登场并走到第一个可见转角；
2. `6.00–9.00秒`：P1绕过转角遇见P2，摄影机把跟拍交给P2；
3. `9.00–11.50秒`：P2绕过第二个转角遇见P3，摄影机把跟拍交给P3；
4. `11.50–13.50秒`：利用P3视线切回P1，P1走出校园并在转角完成实体墙面遮挡；
5. `13.50–18.00秒`：P4真实慢动作及Final Hold。

每次人物交接都必须由实际行走、转角墙面遮挡、墙面离开后的揭示与摄影机跟拍交接组成。人物不得突然弹出、由前一人物Morph而成或在相邻画格中直接替换身份。

## 画面执行

第一段由H3生成一条电影级连续走廊。P1正面走向摄影机，摄影机实体向后跟拍并保持人物比例。模特以轻松自然的慢速在不同位置活动：开关储物柜与整理书本、抱书侧身闪避人流并看手表、看书、靠墙或贴柜聊天并短暂拍肩。每位被选中的模特以正面或四分之三角度望向镜头1.0–1.5秒。结尾必须让P1实际到达第一个转角，墙面进入构图。

第二段跟随P1实体绕过第一个转角。墙面先遮住远处空间，摄影机清除墙面后才揭示原本就在转角后方走来的P2。P1与P2短暂眼神接触并擦身，摄影机跟拍平顺交给P2。

第三段继续跟随P2走到第二个转角，以相同的真实墙面遮挡和侧向视差揭示已经在转角后方的P3。P2作出自然反应，摄影机再交给P3；不得用身份替换式Hard Cut。

第四段必须成为独立的11.50–13.50秒H3 Render Segment，在开头使用Hard Cut，并且不携带P2／P3运动参考帧。摄影机位于校园一侧，以Eye Level正面迎向P1。局部0.00–0.70秒，P1朝镜头跨越门槛，正面或四分之三脸、双眼及五官必须清楚；0.70–1.45秒，P1望向画外主体，以睁大双眼、抬眉和微张嘴形成清楚惊讶反应；1.45–2.00秒，摄影机侧移到相邻墙面或门框后，直至建筑遮满所有像素。禁止只出现P1背影。

第五段接收第四段最后24帧无声画面作为校园Motion Reference。校园建筑、地面、日光、镜头高度、地平线与方向保持不变；P4只提供可见主体的身份、脸、身体、毛发或发型、服装、配饰、数量与相对排列，P4原背景必须舍弃。把P4主体以正确比例、脚底接触、共同日光与接触阴影融合进校园，像同一次真实拍摄。P4主体以约45–60%体感速度慢放，A1保持1倍速；摄影机沿校园既有轴线做极小幅慢速横移，最后0.5秒固定。

## A1连续规则

A1只播放一次。每个隐藏H3 Segment实际上传的音频必须从该Segment的Timeline起点对应到相同A1 Source In。例如Segment从13.50秒开始，就上传A1的13.50秒内容；15秒边界后的Segment从A1 15.00秒继续。禁止从头重播、复制、替换、拉伸或交叉淡化第二份A1。

可以有轻微现场走廊底噪、脚步和衣物声，但必须位于A1下面。没有用户逐字指定时，不生成对白、旁白、歌词或替代音乐；`non_diegetic_music`设为`N/A`。

## 素材时间隔离

只用`existing_media_uses`，不为P1–P4生成替代图，也不生成走廊图：

- P1：0.00–9.00秒与11.50–13.50秒；
- P2：6.00–11.50秒；
- P3：9.00–11.50秒；
- P4：13.50–18.00秒；
- A1：0.00–18.00秒连续播放。

13.50秒后的Media Pool素材只可加载P4与A1，另由程序加入第四段最后24帧无声校园连续性参考。任何人物图不得在不属于自己的时间范围污染其他Segment。

固定编译三个隐藏生成窗口：0.00–11.50秒、11.50–13.50秒、13.50–18.00秒。中间窗口只执行第四段并只加载P1与相同时间位置的A1切片；最后窗口加载P4、对应A1切片与第四段最后24帧的校园Motion Reference。不得把第四段重新并入开场长任务。

## 禁止内容

禁止播放键、快进／后退、点赞、评论、App边框、字幕、Logo、水印和无关文字；禁止看见无人机、摄影机、手机、云台、摄影师、剧组或器材反射。

## 交付检查

输出精确覆盖0.00–18.00秒的五个连续、无重叠Shot。确认P1→P2与P2→P3都有走路、墙面遮挡、转角揭示和跟拍交接；P1正脸、惊讶反应、校园室外与全画面遮挡全部出现在独立11.50–13.50秒Segment；P4主体身份与排列保持准确，但原背景已被同一校园取代并完成光影与地面融合；A1跨Segment连续；最后0.5秒没有新动作。
