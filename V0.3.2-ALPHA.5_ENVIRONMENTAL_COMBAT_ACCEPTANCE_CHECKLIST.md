## Definition of done

- [ ] A fight action can cause a visible, physically plausible response in a nearby person, prop or part of the environment.
- [x] Every authored response has a named cause; the compiler prohibits spontaneous breaking, motion, splashing and collapse.
- [x] Irreversible damage and displaced-object state is carried through later Shots, Segment boundaries, Storyboard edits, save/reload and local rerender metadata.
- [x] P1 remains S1 and P2 remains S2 in mapping; environment/spectator plates explicitly prohibit principal fighters.
- [x] The authored route travels from the indoor wet market through its loading gate into the matching outdoor alley without walking coverage or location reset.
- [x] The actual prompt sent to `MiniMaxH3ReferenceToVideo` contains calculated interaction, damage, crowd, route and acoustic continuity instructions.
- [x] Existing projects, other Special Skills and Design without this Skill retain their current behavior.

- [x] Add a stable Environment Interaction record owned by the Shot/Timeline, not by temporary render output.

## B. Cause-and-effect physics contract — Required

- [x] A physical response is emitted only after a described contact or near-field force.
- [x] One Combat Beat may require at most one primary and one secondary environmental response.
- [x] Reaction order is explicit: body load → attack/defence → contact → object response → crowd response → recovery.
- [ ] Light feedback includes water splash, ice scatter, lamp swing, tank vibration and metal rattle.
- [ ] Medium feedback includes overturned crates, displaced trays, dented stall panels and cracked non-critical glass.
- [x] Heavy feedback is reserved for the authored forced-gate threshold climax.
- [x] Critical destruction is never generated automatically.
- [x] Damage cannot repair itself in a later Shot unless the Timeline explicitly authors a repair or reset.
- [x] Debris, water and loose objects are instructed to respond after impact and in the force direction.
- [x] Unexplained explosions, critical building collapse, debris storms and duplicate fighters are explicitly prohibited.
- [x] The per-Shot physical-response instruction is bounded to one primary and one secondary response.

## Explicit scope boundary

- This feature supplies stateful causal direction and continuity to H3; it is not a deterministic rigid-body physics simulator.
- It does not add Blender, game-engine physics, external compositing, post-generated destruction, TTS replacement or an audio-remixing chain.
- Pixel-perfect identity cannot be mathematically guaranteed by a generative model, but P1/P2 remain the only authoritative character references and identity conflicts must be removed before Queue.
- Large crowds, building-scale collapse, gore and uncontrolled critical destruction are outside the alpha.5 acceptance scope.
