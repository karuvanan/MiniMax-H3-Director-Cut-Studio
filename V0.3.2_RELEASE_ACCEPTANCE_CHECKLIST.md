# MiniMax H3 Director Cut Studio v0.3.2 Release Acceptance

> Candidate baseline: `v0.3.1-alpha.4.8.0`  
> Target: `v0.3.2`  
> Rule: the application version may be promoted only after every **Required** item below has automated or documented evidence.

## A. Historical defect regression — Required

- [x] Gate 1 — logical P/V/A identity, dynamic physical slot mapping and cross-computer media rebasing.
- [x] Gate 2 — Design Apply followed by Timeline move, trim, track and Prompt edits remains synchronized through Undo/Redo.
- [x] Gate 3 — Picture/Video cannot survive on Audio tracks and Audio cannot survive on Video tracks.
- [x] Gate 4 — native 15-second boundaries preserve 24-frame context without replay, collision, reference-slot overwrite or acoustic leakage.
- [x] Gate 5 — missing or stale Picture/WAV/Audio/Video paths are rejected before ComfyUI Queue; inactive legacy Loaders are removed.
- [x] Gate 6 — project-level `unique_media` upload union cannot overwrite Segment-local Loader selection.
- [x] Gate 7 — stable Segment Preview/Final Takes survive partial rerender, project reload, Preview/Final switching and verified cache cleanup.
- [x] Gate 8 — Apply uses one transactional Preflight Report, repairs predictable defects and remains retryable after failure.
- [x] Gate 9 — unlimited Virtual Media Pool and Segment-local Reference Mapping preserve permanent P10+/V4+/A4+ identity.
- [x] Gate 10 — dialogue-duration ripple cannot create Shot-less Segments or orphan editable Text Layers.
- [x] Gate 11 — interrupted render recovery cache, Safe Cleanup and portable Archive obey the durable-data protection contract.
- [x] Old Project Text Layer forward compatibility ignores unknown future metadata while retaining known speech fields.
- [x] Native/Edge/Vox dialogue mode, language lock, speaker identity and exact authored text remain editable Timeline-owned data.
- [x] Generated Master recovery works when saved output fields are empty or old-computer paths are stale.
- [x] Interrupted Monitor Proxy files missing the MP4 `moov` index are rejected and rebuilt atomically.

## B. Long Production Reliability — Required

- [x] Full Range remains backward compatible; `long-form-h3-director` enables Incremental mode explicitly.
- [x] Safe 30-second approval batches never split Dialogue/Voice-over/Lyrics.
- [x] Every completed or failed hidden Segment writes a resumable Project and render-manifest checkpoint.
- [x] Reopening a Project resumes from reusable completed Segments instead of restarting the full Timeline.
- [x] Preview and Final caches, seeds and cumulative approval horizons remain isolated and persistent.
- [x] One failed Segment does not delete or invalidate other approved Segment Takes.
- [x] Shot Take state and stable Segment Take files support local rerender and selective master assembly.
- [x] OOM recovery has an explicit classified retry policy, ComfyUI memory release, bounded retry count and persisted failure reason.
- [x] Interrupted-worker recovery is verified from a durable job/checkpoint rather than only an in-memory UI state.
- [x] Batch job files are project-scoped and cannot collide between two Projects or Studio instances.
- [x] A 90-minute metadata-only architecture stress test verifies Timeline, Segment planning, fingerprints, save/reload and bounded memory without invoking H3.

## C. Storage Optimization & Acceptance — Required

- [x] Workspace root publishes at most one `generated_preview.mp4` and one `generated_output.mp4`.
- [x] Each Segment stores at most one Motion Preview and one Approved Final movie.
- [x] Shot folders contain manifests/references instead of duplicate movie aliases.
- [x] Imported media uses hard links when available and safe copy fallback otherwise.
- [x] Legacy duplicate Shot Takes are removed only after SHA-256 verification against a durable canonical Segment Take.
- [x] Completed render-run caches are removed only after Master and every Segment Take are durable.
- [x] Current-format Take paths and render manifests rebase after copying or renaming the Workspace.
- [x] Storage Report distinguishes durable, reusable, disposable, external and duplicate physical/logical bytes.
- [x] Safe Cleanup provides a dry-run plan and can remove only verified disposable cache/temp/duplicate files while protecting Approved Takes, Masters and resumable caches.
- [x] Archive Project creates a portable archive that excludes disposable cache by default and includes a manifest with file hashes.
- [x] Archive verification proves the canonical Project, workflow, media, Segment Takes and Preview/Final Masters are present and no archived path escapes the Workspace.

## D. Long-form acceptance production — Required

- [x] A deterministic 120-second fixture extends an approved first 45 seconds without regenerating it.
- [x] Five new local Segment fixtures extend the production by 75 seconds and assemble one complete 120-second H.264/AAC Master.
- [x] Editing one middle Segment replaces only its Take; outer Segment hashes remain unchanged.
- [x] Save, close and reopen restores Timeline, Master, Take state, approval horizon and next pending batch.
- [x] Program Monitor accepts the complete Master only through the validated/atomic proxy path.
- [x] Cross-computer archive/copy resolves workflow, media, Take, manifest and generated-output paths from the current Workspace.

## Explicit scope boundary

- A single Studio instance still runs one ComfyUI job at a time. Project-scoped job files permit safe multi-Project recovery and separate Studio instances, but a centralized concurrent multi-Project scheduler is deferred.
- The 90-minute check is a metadata/planning/save-load stress test. It intentionally does not spend H3 generation time or VRAM on a 90-minute movie.
- The 120-second test uses deterministic local H.264/AAC Segment fixtures so assembly, selective replacement, storage and portability are repeatable without external model availability.
